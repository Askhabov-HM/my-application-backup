My Application Backup creates encrypted copies of selected application data and stores them in the account owner's Google Drive.

How your data is handled ↗

How it works

From application data to a recoverable backup.

  1. 01

    Create a consistent copy

    The utility takes snapshots of the application databases selected by its owner.

  2. 02

    Encrypt before upload

    Backup contents are encrypted on the owner's host before they are transferred to Google Drive.

  3. 03

    Keep and verify

    Backups follow the owner's retention settings. Download and restore checks help confirm that saved copies can be recovered.

Google Drive access

Permission with a specific purpose.

The Google connection is used to upload, list, download and remove backup files according to the owner's settings.

The utility requests the drive.file permission. It can access files created by this application or explicitly made available to it. It does not request access to Gmail, contacts or calendars.

This is an owner-operated utility. This website provides information; it does not provide a public sign-up or collect Google credentials.
